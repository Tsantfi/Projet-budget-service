# Haigana

C'est un application web qui est utilisé dans le Service Régioanl du Budget. Il permet de gérer les entités
dans et importé les données automatiquement

## Concernant Hainga

Haigana est composé par:

- Gestion de droit d'accès à l'utilisateur.

- Recensement automatique des entités.

- Sortie de quitus en fonction d'un récensement.

## Version de l'application

La version de l'application est de 1.0

## Outil pour son réalisation

Les outils nécessaire pour son réalisations sont:

- Javascript qui permet de donnée du style au site.
- Java pour lasécurisation de donnée.
- React Js pour le Framework Javascript.
- Spring boot pour le Framework Java.

## Les méthodes pour la réalisation du projet

Les méthodes utilisé sont:

- Import des fonctions par nomdu fichier pour l'appelé dans un autre page.
- Appelle des API dans le Front-end pour POST, DELETE, PUT, DELETE.
- API REST Java.

## Utilisation de ce projet

Ce projet sera utilisé dans le Ministère de l'Economie et des Finances Boeny au sein de Service Régional
du Bugdet Boeny.
